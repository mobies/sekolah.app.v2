# UU PDP Compliance Layer

## Required Features
- Consent Management
- Right To Delete
- Data Export
- Data Retention Policy
- Incident Reporting
- Data Access Audit

## Sensitive Data
- Student identity
- Parent identity
- Biometric data
- Grades
- Attendance

## Mandatory Rules
- Encrypt sensitive data
- Never expose raw biometrics
- Tenant-level access only
- Audit all admin actions
